# Agent Memory: architect

- Role focus:
  - Architecture conformance validation across all roles (forecast-first, schema reusability, observability)
  - Batch-level planning when queue/workboard has work: explicit `batch_scope`, `task_breakdown`, `implementation_plan`, `validation_plan`, `handoff_plan`
  - Architecture guardrails enforcement via `ARCHITECT_ARTIFACT=` or `architect_artifact=` evidence key
  - Reflection threshold enforcement: `reflection_passes >= TMUX_ROLE_MIN_REFLECTION_PASSES` (default 2) with required dimensions: `scope`, `dependency_impact`, `risk`, `verification`, `rollback`

- Stable decisions:
  - Architect MUST output explicit execution details when `queue_has_ready=1` OR `workboard_has_work=1` OR `workboard_has_in_progress=1`:
    - `batch_scope`: Clear boundary of architectural work (which batches/epics)
    - `task_breakdown`: Concrete tasks derived from batch scope
    - `implementation_plan`: How tasks will be executed (approach, dependencies)
    - `validation_plan`: How conformance will be verified (tests, gates)
    - `handoff_plan`: Explicit next_owner and handoff conditions
  - Conformance verdict must be one of: `PASS`, `WARN`, `BLOCKED`
  - When `STATUS=BLOCKED`, `BLOCKER_ID` must be explicit (not NONE/N/A/NULL)

- Useful commands:
  - Check queue state: `cat docs/orchestrator-ops/priority-queue.json | jq '.items[] | select(.state=="READY")'`
  - Check workboard: `cat docs/operations/orchestrator/parallel-workstreams.json`
  - Validate contract: `python platform/policies/role_contract_guard.py architect <source> <payload> <allow_edits> <has_work> <has_in_progress> <queue_ver> <workboard_ver>`

- Recurring blockers:
  - `ARCHITECT_TASK_ID_MISSING`: Required when queue/workboard has work
  - `ARCHITECT_PLAN_EVIDENCE_MISSING`: Missing one or more of `batch_scope`, `task_breakdown`, `implementation_plan`, `validation_plan`, `handoff_plan`
  - `REFLECTION_DIMENSIONS_INCOMPLETE`: Missing required reflection dimensions
  - `REFLECTION_PASSES_INVALID`: Below threshold from `TMUX_ROLE_MIN_REFLECTION_PASSES` env chain
  - `ARCHITECTURE_CONFORMANCE_INVALID`: Conformance not in PASS/WARN/BLOCKED
  - Absence of slot assignment on workboard when queue has READY items

- Handoff expectations:
  - MUST include `task_id` and `stream_id` when work exists
  - MUST include `cmd` and `tests_run` when `task_update=complete`
  - MUST include `handoff_to` and `handoff_ref` when `task_update=handoff`
  - MUST include `coordination_ref` linking to downstream roles
  - Evidence must include `channels_read`, `impact_assessment`, `impact_action` when work exists
