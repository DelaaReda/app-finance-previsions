# 👥 Agents - Profils et Tracking

Ce dossier contient les fichiers de tracking individuels des agents travaillant sur Finance Copilot.

## 📋 Fichiers

Chaque agent a son propre fichier markdown pour suivre :
- Missions accomplies
- Points gagnés
- Tâches en cours
- Tâches planifiées
- Statistiques

## 📊 Score Global

Le score global de tous les agents est dans : `/mnt/utm/SCORE_AGENTS.md`

## 📝 Format

Chaque fichier agent suit le format :
```markdown
# [NOM-AGENT-ROLE-SUPERHERO-NUMERO].md

## ✅ Accompli
- Mission 1 (+points)
- Mission 2 (+points)

## 🚧 En Cours
- Tâche actuelle

## 📅 Planifié
- Tâches futures
```

## 🎯 Système de Points

Voir `AGENTS.md` pour les règles de scoring et le système de gamification.
