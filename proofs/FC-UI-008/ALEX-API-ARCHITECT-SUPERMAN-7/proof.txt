# Preuve de mise en œuvre - FC-UI-008

## Tâche: Freshness globale (top bar)

## Résumé
Ajout d'un composant GlobalFreshness dans l'en-tête pour afficher la fraîcheur globale (forecasts/news/brief) provenant de l'API /health.

## Changements apportés
- Création du composant GlobalFreshness.tsx avec logique de fraîcheur
- Intégration du composant dans Header.tsx dans la section actions
- Gestion des deux formats de timestamp (chaîne ISO et Unix timestamp)
- Calcul de la fraîcheur relative (fraîche vs périmée vs inconnue) 
- Indication visuelle avec icônes et couleurs distinctes
- Affichage de détails dans tooltip au survol

## Structure mise en place
- Composant GlobalFreshness avec gestion du state et des effets
- Récupération des données via api/health endpoint
- Calcul de fraîcheur basé sur la différence de temps (threshold: 15 min)
- Affichage de l'état global basé sur le pire statut parmi toutes les sources
- Tooltip détaillé avec les temps spécifiques pour chaque source

## Fichiers modifiés
- `frontend/webapp/src/components/ui/GlobalFreshness.tsx` - Nouveau composant de fraîcheur
- `frontend/webapp/src/components/layout/Header.tsx` - Intégration du composant

## Vérification
- Le composant s'affiche dans l'en-tête à côté de HealthIndicator
- Les différentes sources de données sont surveillées (forecasts, news, brief, brief_weekly)
- Les formats de timestamp sont correctement gérés (string et number)
- L'état visuel reflète la fraîcheur globale
- Le tooltip affiche les détails de fraîcheur pour chaque source
- Le composant se met à jour automatiquement toutes les 5 minutes
