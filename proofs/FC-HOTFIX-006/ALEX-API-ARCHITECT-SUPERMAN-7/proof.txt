# Preuve de mise en œuvre - FC-HOTFIX-006

## Tâche: Script start/stop/status sans `timeout` (démarrage stable sur macOS)

## Résumé
Modification des scripts shell pour remplacer les commandes `timeout` par des boucles d'attente (wait loops) pour assurer le bon fonctionnement sur macOS.

## Changements apportés
- Ajout fonction `start_backend_only()` dans `finance-copilot.sh` et `copilot.sh`
- Modification `finance-copilot.sh` pour inclure une section backend avec export PYTHONPATH
- Remplacement de la commande `timeout` par une boucle d'attente (10 tentatives, 2s d'intervalle)
- Utilisation de `curl -f "http://localhost:8050/api/health"` pour vérifier la disponibilité du backend

## Vérification
Le script attend que le backend réponde à l'endpoint `/api/health` au lieu d'utiliser une commande `timeout` qui n'existe pas sur macOS.

## Résultats
- Démarrage backend: ✅ (`bash finance-copilot.sh start-backend`)
- Export PYTHONPATH: ✅ (`export PYTHONPATH="$(pwd)/copilot-app/backend"`)
- Boucle d'attente: ✅ (attend que l'API soit prête)
- PID tracking: ✅ (écriture dans /tmp/finance_copilot_backend.pid)
