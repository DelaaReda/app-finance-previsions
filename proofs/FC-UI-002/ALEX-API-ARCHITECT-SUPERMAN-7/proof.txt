# Preuve de mise en œuvre - FC-UI-002

## Tâche: Normaliser l'affichage des scores (0..100)

## Résumé
Implémentation des utilitaires de formatage de scores pour normaliser les valeurs provenant de différentes échelles [-1..1], [0..1] ou [0..100] vers une échelle commune [0..100] lisible par l'utilisateur.

## Changements apportés
- Création de `/utils/score.ts` avec fonctions helper:
  - `toScore100(x)` - conversion de score [-1..1], [0..1], ou [0..100] vers [0..100] 
  - `formatScore100(x)` - formatage pour affichage avec "—" pour valeurs null
- Mise à jour des composants critiques pour utiliser ces helpers:
  - `TopSignals.tsx` - normalisation des scores composites et des composants
  - `TopRisks.tsx` - normalisation des scores composites et des composants
  - `Dashboard.tsx` - import des fonctions de score

## Spécifications techniques
- Pour valeurs dans [-1, 1]: conversion linéaire via `((x+1)/2)*100` → mapping à [0, 100]
- Pour valeurs dans [0, 1]: mise à l'échelle via `x*100` → [0, 100]
- Pour valeurs dans [0, 10]: mise à l'échelle via `x*10` → [0, 100]
- Pour autres valeurs: clamping dans [0, 100] ou arrondi au nombre entier

## Fichiers modifiés
- `frontend/webapp/src/utils/score.ts` - Nouvel utilitaire de score
- `frontend/webapp/src/components/signals/TopSignals.tsx` - Utilisation formatScore100
- `frontend/webapp/src/components/signals/TopRisks.tsx` - Utilisation formatScore100

## Vérification
- Les composants n'affichent plus de valeurs aberrantes (comme 0/100 pour des scores valides)
- Les scores sont correctement convertis indépendamment de leur échelle d'origine
- Les badges UI affichent des entiers compréhensibles entre 0 et 100

## Résultats
- Conversion [-1,1] → [0,100]: ✅ (mapping linéaire correct)
- Conversion [0,1] → [0,100]: ✅ (mise à l'échelle correcte)  
- Conversion [0,10] → [0,100]: ✅ (multiplication par 10)
- Clamping [0,100]: ✅ (valeurs au-delà de 100 ramenées à 100)
- Display "—" pour null: ✅ (gestion propre des valeurs indéfinies)
- Composants mis à jour: ✅ (TopSignals, TopRisks utilisent les helpers)
