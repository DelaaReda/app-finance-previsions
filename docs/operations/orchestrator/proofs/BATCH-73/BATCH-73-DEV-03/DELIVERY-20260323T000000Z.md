## Delivery Evidence

### 1. Brief of Day Contract ✅

**Endpoint:** `GET /api/copilot/start`

**Required fields verified:**
- `summary` - String < 200 words
- `market_sentiment` - BULLISH/BEARISH/NEUTRAL/UNKNOWN
- `top_signals` - List of signal objects
- `top_risks` - List of risk objects
- `generated_at` - ISO timestamp with Z suffix
- `freshness` - ISO timestamp with Z suffix
- `source` - List of source strings

**Fallback behavior:** When no snapshot available, returns fallback brief with `market_sentiment=UNKNOWN` and `source=["brief_daily_fallback"]`.

### 2. Ask/Open Entry Points ✅

**Ask entry points:**
- Returned in `response.data.ask` array
- Each item has: `id`, `kind=ask`, `label`, `target`, `prefill.question`
- Example: "Poser une question" → `/copilot/ask`

**Open entry points:**
- Returned in `response.data.open` array
- Each item has: `id`, `kind=open`, `label`, `target`
- Example: "Brief du jour" → `/brief/daily`

### 3. Ask Endpoint Contract ✅

**Endpoint:** `POST /api/copilot/ask`

**Request:**
```json
{
  "question": "Should I buy NVDA today?",
  "tickers": ["NVDA"],
  "conversation_id": "optional-thread-id"
}
```

**Response fields:**
- `question` - Echoed user question
- `answer` - String response
- `verdict` or `action` - buy/sell/hold
- `horizon` - 1d/1w/1m
- `confidence` - 0.0 to 1.0
- `why` or `reasoning` - List of reasons
- `conversation` - Optional thread metadata (BATCH-73-DEV-02)
