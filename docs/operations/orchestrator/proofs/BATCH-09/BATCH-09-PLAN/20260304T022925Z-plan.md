## Méthode deep-diagnostic (inspirée analyse-claude.odt)
Appliquer systématiquement sur bugs complexes:
1. Symptôme runtime exact (monitor/health/queue/workboard) + timestamp.
2. Chaîne causale complète (pas juste l’erreur finale): source -> propagation -> impact blocant.
3. Vérification des hypothèses structurelles (ID parsing, stream grouping, alias role, path root).
4. Vérification des états cachés/stales (tmux sessions, locks `*.run.lock/*.memory.lock`, fallback engine).
5. Correctif minimal et testable + preuve avant/après.
