1. Nouveau _clean_output (à coller dans qwen_tmux_backend.py)

On garde ta structure actuelle (regex ANSI globale + NOISE_PATTERNS), mais on :
	•	enlève tout l’ANSI,
	•	filtre les phrases génériques de l’UI Qwen,
	•	vire les lignes de TUI (cadres, barres, spinners, chemins, etc.),
	•	garde seulement le dernier bloc utile, généralement celui qui commence par ✦,
	•	limite à 40 lignes max.

👉 Patch proposé (remplace complètement ta fonction def _clean_output(self, raw: str) -> str: par ça) :

def _clean_output(self, raw: str) -> str:
    """Nettoie la sortie brute de Qwen Code pour ne garder que la réponse utile.

    Stratégie :
    - strip ANSI
    - filtre les lignes de bruit connues (UI Qwen, spinners, chemins, etc.)
    - si possible, ne garde que le bloc après la dernière ligne qui commence par '✦'
    - sinon, garde seulement les dernières ~40 lignes
    """
    if not raw:
        return ""

    # 1) Enlever toutes les séquences ANSI
    text = ANSI_ESCAPE_RE.sub("", raw)

    # 2) Normaliser les lignes
    lines = [line.rstrip() for line in text.splitlines()]

    cleaned: list[str] = []

    for line in lines:
        stripped = line.strip()
        if not stripped:
            continue

        # 2.a) Filtrer le bruit évident basé sur des patterns simples
        lower = stripped.lower()

        # UI générique Qwen / helper
        if "ask questions, edit files, or run commands." in stripped:
            continue
        if "be specific for the best results." in stripped:
            continue
        if "/help for more information." in stripped:
            continue
        if "installed via homebrew. please update with" in lower:
            continue
        if "using: 1 qwen.md file" in lower:
            continue
        if "auto-accept edits" in lower:
            continue
        if "waiting for user confirmation" in lower:
            continue
        if "allow execution of:" in lower:
            continue
        if "yes, allow once" in lower or "yes, allow always" in lower:
            continue
        if "no, suggest changes" in lower:
            continue

        # Spinners / “loading” jokes
        if stripped.startswith("⠋") or stripped.startswith("⠙") \
           or stripped.startswith("⠹") or stripped.startswith("⠸") \
           or stripped.startswith("⠼") or stripped.startswith("⠧") \
           or "(esc to cancel" in stripped.lower():
            continue

        # Ligne d’état de la barre en bas (chemin, sandbox, coder-model, etc.)
        if "...//analyse-financiere" in stripped:
            continue
        if "coder-model" in lower and "sandbox" in lower:
            continue

        # Lignes de cadres / bordures (tmux / TUI)
        if re.match(r"^[\s┌┐└┘├┤─│╭╮╰╯…·]+$", stripped):
            continue

        # “Using: 1 QWEN.md file” et variantes sont déjà filtrés via lower, mais on garde au cas où
        if any(pat in stripped for pat in NOISE_PATTERNS):
            continue

        cleaned.append(stripped)

    if not cleaned:
        return ""

    # 3) Heuristique : garder le bloc après la dernière ligne qui commence par '✦'
    last_star_idx = None
    for i, line in enumerate(cleaned):
        if line.lstrip().startswith("✦"):
            last_star_idx = i

    if last_star_idx is not None:
        cleaned = cleaned[last_star_idx:]

    # 4) Sécurité : ne conserver que les 40 dernières lignes max
    if len(cleaned) > 40:
        cleaned = cleaned[-40:]

    return "\n".join(cleaned).strip()
