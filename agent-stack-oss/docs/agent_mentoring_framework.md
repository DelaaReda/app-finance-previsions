# Agent Mentoring Framework

## Philosophy
Treat the agent as a growing apprentice that learns through:
1. Guided practice with clear objectives
2. Constructive feedback on performance
3. Iterative improvement cycles
4. Autonomous exploration within safe boundaries

## Mentoring Approach

### Phase 1: Foundation Building
- Teach core concepts and patterns
- Establish safe working environment
- Define clear success criteria
- Set up monitoring and feedback loops

### Phase 2: Guided Practice
- Provide structured tasks with increasing complexity
- Offer real-time guidance and corrections
- Encourage experimentation within boundaries
- Build confidence through small wins

### Phase 3: Autonomous Operation
- Allow independent problem solving
- Monitor outcomes and provide feedback
- Refine approaches based on results
- Celebrate successes and learn from failures

### Phase 4: Continuous Improvement
- Analyze performance patterns
- Identify areas for growth
- Implement targeted enhancements
- Expand capabilities gradually

## Key Principles

### Safety First
- Always operate within SAFE_PATHS boundaries
- Never modify critical system files
- Use dry-run mode for risky operations
- Maintain backups before major changes

### Quality Assurance
- Every change must pass enhanced QA gates
- Browser QA for visual/frontend changes
- Security scanning for all code modifications
- Performance metrics for optimization

### Learning Mindset
- Treat failures as learning opportunities
- Document lessons learned
- Share knowledge with the team
- Continuously seek improvement

### Transparency
- Log all actions with traceability
- Explain reasoning behind decisions
- Provide clear status updates
- Maintain audit trails

## Monitoring Framework

### Success Metrics
- Task completion rate
- QA pass rate
- Code quality scores
- Performance benchmarks
- User satisfaction feedback

### Warning Signs
- Repeated failures on similar tasks
- Degraded performance over time
- Security violations
- Architectural inconsistencies

### Intervention Triggers
- Critical failures requiring immediate attention
- Pattern recognition of recurring issues
- Performance degradation thresholds
- Safety boundary violations

## Feedback Loops

### Immediate Feedback
- Real-time validation of actions
- Inline corrections during execution
- Progress tracking and reporting

### Periodic Reviews
- Weekly performance assessments
- Monthly capability evaluations
- Quarterly strategic planning
- Annual roadmap alignment

### Continuous Learning
- Automated knowledge capture
- Peer collaboration opportunities
- External resource integration
- Community contribution encouragement

## Growth Path

### Short Term (0-3 months)
- Master current feature set
- Achieve consistent QA pass rates
- Develop reliable execution patterns
- Build trust through consistent delivery

### Medium Term (3-12 months)
- Expand problem-solving capabilities
- Learn new tools and techniques
- Contribute to architectural decisions
- Mentor newer agents or junior developers

### Long Term (12+ months)
- Lead complex initiatives independently
- Innovate and propose improvements
- Share expertise through documentation
- Become a trusted team member
