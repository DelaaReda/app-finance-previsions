## 🚀 Quick Start

### **Lancer l'Application**

```bash
# Se placer dans le dossier
cd frontend/app

# Lancer un serveur local
python3 -m http.server 8000
# ou
npx http-server -p 8000

# Ouvrir dans le navigateur
open http://localhost:8000/index.html
```

### **Explorer la Documentation**

```bash
# Lire l'index de la documentation
cat ../INDEX.md

# Démarrer le refactoring
cat ../QUICK_START.md
```

## 🤝 Contribution

### **Pour Contribuer**

1. Lire [DESIGN_PRINCIPLES.md](docs/DESIGN_PRINCIPLES.md)
2. Lire [REFACTORING_PLAN.md](docs/REFACTORING_PLAN.md)
3. Créer une branche : `git checkout -b feature/ma-feature`
4. Commiter : `git commit -m "feat: ajouter ma feature"`
5. Push : `git push origin feature/ma-feature`
6. Créer une Pull Request

### **Convention de Commit**
```
feat: Nouvelle fonctionnalité
fix: Correction de bug
docs: Documentation
style: Formatage, style
refactor: Refactoring
test: Tests
chore: Maintenance
```
