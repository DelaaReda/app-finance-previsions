# Roadmap

Dernière mise à jour : 2025-11-02

## Vision

Copilote financier avec React UI, FastAPI backend, Lakehouse data, RAG sur 5+ ans.

## V1 : Core Pages (Q4 2025)

- ✅ Data lakehouse v2
- ✅ API FastAPI v2
- ⏳ React migration: Dashboard, Macro, Stocks, News, MarketBrief, TickerSheet
- ⏳ QA gates: ruff/mypy/pytest + tsc/eslint/build
- ⏳ E2E smoke (5 pages)

## V2 : Advanced Features (Q1 2026)

- Backtests: simulation rules, equity curves, stats
- Forecasts: multi-horizon, distribution, confiance
- LLMJudge: auto-évaluation réponses
- RAG indexer 12-24 mois news
- Copilot UX: réponses structurées + export MD

## V3 : Scale & Ops (Q2 2026)

- Observabilité /api/freshness
- Multi-univers support
- Export Brief → PDF/MD
- User personalization (watchlists)

## Définition of Done

- Data présente (7-30 jours min)
- API stable + docs
- Webapp build OK + QA verte
- Brief montre TopSignals/TopRisks cohérents
- Docs à jour
